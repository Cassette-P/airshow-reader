# Sinica Podcast 主播与专业术语配置（sinica.md）

## 固定主播与嘉宾归一化规则（Speaker）

- 固定主播标准英文名：`Kaiser Kuo`（中文译文中人名直接保留 `Kaiser` 或 `Kaiser Kuo`，不要生硬音译为“凯泽·郭”）。
- 每期飞行嘉宾：必须优先从本集提供的 **Episode Show Notes** 中提取嘉宾的准确英文全名作为 `speaker` 标签（例如 `Evan Feigenbaum`、`Joe Studwell`、`Dan Wang`），严禁在简介已给出姓名时偷懒标为 `Guest`；仅在确实无法辨认的多人插话场景使用 `Guest`。
- 中文译文中，欧美学者、记者与播客嘉宾人名直接保留英文原名；众所周知的中国历史/政治人物与机构还原为标准中文名。

本节目讨论大量中国政治、经济、科技与社会议题，英文口播中的中国固有概念必须**精准还原为地道中文原词**，严禁逐字机翻：

- **政治与机构**：PRC（中华人民共和国 / 中国大陆）、CPC / CCP（中国共产党 / 中共）、PLA（中国人民解放军）、Third Plenum（三中全会）、Two Sessions（两会）、14th / 15th Five-Year Plan（“十四五” / “十五五”规划）、NDRC（国家发改委）、PBOC（中国人民银行 / 央行）、MOFCOM（商务部）、NPC（全国人大）、CPPCC（全国政协）、Politburo Standing Committee（中央政治局常委会）、Global South（全球南方）、Wolf Warrior Diplomacy（战狼外交）

## 翻译文风与校对红线

- 文风对标《财新》/《经济学人·商论》的深度政经访谈：冷静、克制、保留原话的思辨层次与学术/政策细微差别，不夸大、不添油加醋。
- 节目中提及的书籍、论文、智库报告与专栏名，保留英文原名或加注公认中文书名，切勿胡乱自造译名。
- 英文缩写与专有概念保持规范格式，严禁同音错别字。
